# Experiment artefacts

Everything here was produced by the CLI in this repository — no notebook, no manual
editing. Each directory is self-describing:

```
<run>/
  REPORT.md          tables + figures, regenerated by `evla report --results <run>`
  LEADERBOARD.md     paired comparison against a reference config (McNemar)
  leaderboard.json   machine-readable leaderboard
  summary.json       all results, concatenated
  <config>.json      one file per config: settings, per-episode records, latency, safety
  *.png              success rates / Pareto / latency / learning curve
  videos/            one recorded episode per config that asked for it
```

| directory | what it answers |
|---|---|
| `pusht_learning_curve/` | does more fine-tuning keep helping? (zero-shot vs 4k/8k/12k/16k/20k, plus LoRA r=16) |
| `pusht_sweep/` | precision × execution mode × flow steps at fixed weights |
| `pusht_toy_chunking/` | receding vs open-loop vs temporal ensembling on the toy task (CPU) |
| `videos/` | recorded rollouts of the fine-tuned policy |
| `deploy_sim.json` | fixed-rate deployment runtime report (deadline misses, safety counters) |

Regenerate any markdown without a GPU:

```bash
evla report --results results/pusht_sweep
```

Machines: one RTX 3090 (24 GB), batch 32 for training, batch 1 for all inference.
Latency numbers were taken with the GPU otherwise idle; `p50/p95` include image
preprocessing and normalisation.
